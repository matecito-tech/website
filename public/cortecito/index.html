Dudas

Preguntas frecuentes

¿Esto es el sistema real? +

Es una demo estática: la interfaz se parece a la del producto, pero los datos son ficticios y viven solo en tu navegador. No hay servidor ni base de datos detrás, así que podés probar sin miedo.

¿Qué pasa con lo que escribo? +

Nada sale de tu dispositivo. Los turnos de prueba se guardan en el almacenamiento local del navegador y se borran con el botón «Reiniciar demo».

¿Puedo tener varias barberías? +

Sí. El sistema es multi-negocio: cada barbería tiene su marca, su dominio y sus datos aislados a nivel de base de datos (PostgreSQL con seguridad por filas).

¿Anda bien en el celular? +

Se diseñó primero para el celular: botones de al menos 48 px, barra inferior con ícono y etiqueta, y todo gesto tiene un botón equivalente. Además se instala como app (PWA).

¿Cuánto cuesta? +

Todavía no publicamos precios: cada barbería se configura a medida, con su marca y su dominio. Escribinos, contanos cómo trabajás y te pasamos una propuesta.

¿Mis clientes tienen que crear una cuenta? +

No. Reservan con nombre y teléfono, y el sistema los recuerda en su dispositivo. Si quieren, pueden ingresar con Google para ver su perfil y sus turnos.

¿Es de código abierto? +

El producto es de Matecito Tech con licencia propietaria; esta demo existe para que lo pruebes. Para licencias o una instalación a medida escribinos desde el contacto.
